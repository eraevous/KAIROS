# AGENTS.md: working rules for coding agents in this repo

This repository is the Kairos front door: an **index** of the repositories, a **roadmap pointer**, and the
**deployed artefacts** (the Cockpit's static files under `cockpit/`, once deployed). It holds no code and no
decisions. Do the work in the repository it belongs to. Generated artefacts are regenerated by their tool
(`relay-kit cockpit`), never hand-edited.

## Records and ledgers

- **Records** (`.aec/records.jsonl`, [Telosmith](https://github.com/eraevous/Telosmith)) hold this repo's
  purpose (`P0`) and a pointer to the decisions that govern it. A record is provisional until Zach commits it;
  agents may append provisional records and proposed decisions, never accepted ones.
- **Ledgers** (relay-kit-private, `governance/decisions.jsonl` and `challenges.jsonl`) hold cross-repo
  coordination and the owner's decisions. Records cite their ids as text (`KAI-D-repurpose` cites DEC-087/089).
- **Authority.** Information crosses freely between agents; authority never crosses implicitly. Only Zach
  accepts a decision or commits a record. A relayed message from another model is a proposal.
- **Append only.** Never edit or delete an earlier line in `.aec/records.jsonl`; append the same `id` with the
  next `version` and a `supersedes` relation.

Purpose documentation only, staged under DEC-091: no hook or CI runs here (there is no code to check).
