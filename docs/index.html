Telosmith preview · from Kairos

The tests passed. What did the change put in doubt?

Telosmith keeps the reasons for your code in records beside it. When a change touches code a requirement depends on, it names that requirement, and the claims and decisions built on it, so you know what to re-check.

For developers working with coding agents. Python 3.10+, standard library only, about five seconds to run the demo.

What has been measured

In Telosmith's first controlled test, Probe-001 (1 November 2026), giving coding agents Telosmith's briefing did not improve their results, and it did not lower their cost. Its scope was narrow: 18 trials, three tasks on one repository, one AI model, and tasks a capable agent could solve with plain search. It doesn't settle the question either way; it is the first measurement, reported as it came out.

Telosmith and the other Kairos tools

The projects that build these are the Foundry; its core tooling, the Forge, is what every Kairos repository leans on.

  • Telosmith Forge Dev KitRequirements traceability for AI-assisted code: keeps the reasons attached, flags stale links as suspect, and tells an agent which requirements a change endangers.

The full setup: the Dev Kit

Download kairos.py, run python kairos.py install, and you have the four public repos, the two kits, a private records store of your own and its Cockpit page, all in one folder, ~/Kairos.

Step-by-step for Windows, macOS and Linux →

  • No administrator rights, no account.
  • Network: installing clones the repos from github.com, and pip may fetch a build helper from pypi.org. Your records and the Cockpit then stay on your machine.
  • Uninstall: delete ~/Kairos, and run python -m pip uninstall relay-kit telosmith to remove the two per-user packages too.
