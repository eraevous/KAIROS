The map

Every public repo, what it is, who it serves, and its honest state, copied from the START HERE README on 2026-11-06. None of the tools is on PyPI yet.

All public tools are plain Python, stdlib-only in the kits, Python 3.12+ recommended.

Telosmith

Keeps the recorded reasons for code attached to the code. check validates the records; code-impact tells an agent (or a human) which written requirements, claims and decisions a change endangers. Standalone, with Spec Kit, or inside another agentic-coding setup.

Who it serves
Developers and teams using coding agents
State
0.5.0 on main; tag pending; 300+ tests; docs/demo.md is a 90-second walkthrough

Install

pip install "git+https://github.com/eraevous/Telosmith.git@main"
aec --help        # the command; `telosmith` is an alias

Then follow docs/demo.md (90 seconds, real output).

Fathom

Deterministic, offline data-review reports: a data dictionary, structure findings with the threshold printed beside each verdict, time-series and panel structure, a liftoff Brief that asks what the data cannot tell you. Byte-identical reruns; nothing leaves your machine.

Who it serves
Analysts; anyone handed a CSV they didn't make
State
specs 001–019 merged; two-stage flow (liftoff → profile)

Install

git clone https://github.com/eraevous/Fathom && cd Fathom
python3 -m venv .venv && .venv/bin/pip install -e '.[test,exports]'
.venv/bin/guide liftoff your.csv --out out/discovery     # stage 1: Brief + Configurations
.venv/bin/guide profile your.csv --config liftoff.yaml --out out/report   # stage 2

Runs with every socket blocked; the tests prove it.

relay-kit

The coordination kit: handoffs with ids and states, append-only decision and challenge ledgers, chat capture and cross-model relay, read-only export, a static Cockpit control surface, an MCP server.

Who it serves
People running more than one AI assistant on one project
State
v0.1.0; export@1, mcp@1, cockpit@2+

Install

pip install "relay-kit @ git+https://github.com/eraevous/relay-kit@v0.1.0"
relay-kit init my-records && relay-kit status --root my-records
relay-kit cockpit --root my-records --out ./cockpit      # a static page; open index.html

Not a Claude user? The kit is being made installable from instructions alone for ChatGPT, Codex and others; say what broke.
